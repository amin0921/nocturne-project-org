# Nocturne 🎧

A dark, glassy desktop music player — made for my own Windows PC.

## Download

Get the latest version (Windows installer) from the

## Features

- Dark glassy UI with an amber accent
- Offline playback of your own music files
- Frameless transparent window

## Built with

- Tauri v2 + React 18 + TypeScript + Tailwind CSS
- SQLite + Zustand

# Nocturne 🎧

Nocturne is a desktop music player app I'm building — a dark, glassy, offline player with an amber accent, made for my own Windows PC.

## Features
- Dark glassy UI with an amber accent
- Offline playback of your own music files
- Frameless transparent window

## Built with
- Tauri v2 + React 18 + TypeScript + Tailwind CSS
- SQLite + Zustand
